# 📋 Manual Testing Portfolio — OpenCart E-commerce

A comprehensive manual QA documentation portfolio for [OpenCart Demo](https://demo.opencart.com), showcasing professional test cases, bug reports, SQL test queries, and exploratory testing notes.

## 📌 About This Project

This project demonstrates manual QA skills through structured documentation of testing activities performed on the OpenCart demo e-commerce platform. It follows industry-standard formats used in professional QA teams.

## 📁 Project Structure

```
proyecto3-manual-testing/
```

## 🧩 What's Documented

### ✅ Test Cases
Structured test cases following the format:
- **ID** — Unique identifier
- **Title** — Clear, action-based description
- **Preconditions** — Required state before execution
- **Steps** — Numbered, specific steps
- **Expected Result** — What should happen
- **Actual Result** — What happened during execution
- **Status** — Pass / Fail / Blocked

### 🐛 Bug Reports
Professional bug reports including:
- **Summary** — One-line description
- **Environment** — Browser, OS, version
- **Severity & Priority** — Impact classification
- **Steps to Reproduce** — Exact reproducible steps
- **Expected vs Actual** — Clear comparison
- **Evidence** — Screenshot references

### 🗄️ SQL Queries
Database validation queries for:
- Verifying user registration data
- Checking order records
- Validating product inventory
- Confirming price consistency

## 🧠 Key Concepts Demonstrated

- ✅ Test case design (positive, negative, boundary)
- ✅ Bug lifecycle documentation
- ✅ Severity vs Priority classification
- ✅ SQL for QA (data validation queries)
- ✅ Exploratory testing with structured notes
- ✅ Test coverage analysis
