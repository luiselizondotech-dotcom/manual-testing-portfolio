## 🧩 What's Documented

### ✅ Test Cases
Structured test cases following the format:
- **ID** — Unique identifier
- **Title** — Clear, action-based description
- **Preconditions** — Required state before execution
- **Steps** — Numbered, specific steps
- **Expected Result** — What should happen
- **Actual Result** — What happened during execution
- **Status** — Pass / Fail / Blocked

### 🐛 Bug Reports
Professional bug reports including:
- **Summary** — One-line description
- **Environment** — Browser, OS, version
- **Severity & Priority** — Impact classification
- **Steps to Reproduce** — Exact reproducible steps
- **Expected vs Actual** — Clear comparison
- **Evidence** — Screenshot references

### 🗄️ SQL Queries
Database validation queries for:
- Verifying user registration data
- Checking order records
- Validating product inventory
- Confirming price consistency
